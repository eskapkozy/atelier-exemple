# Projet d'exemple de l'atelier

Une forêt aléatoire sur un jeu synthétique de 200 000 lignes, écrite en objets
(`projet/donnees.py`, `projet/modele.py`). Le fichier principal est `entrainer.py`.

Dans le terminal de l'atelier :

    calcul connexion          # une fois par session : se connecter à Google
    calcul lancer entrainer.py

Colab clone ce dépôt au commit courant et joue `entrainer.py`. Le journal revient
dans `sorties/`.
